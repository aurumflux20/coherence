# 180 IQ vs 320 IQ (how we build Coherence)

## 180 IQ (clever)

- Seven rungs, many names, impressive diagram  
- Separate modules for every concern  
- Smart heuristics, NLP “violation detection,” dashboards  
- “Platform for agent reality”  
- User must learn *our* taxonomy to get value  

**Feels smart. Dies under its own weight.**

---

## 320 IQ (simple · lethal)

**One law. Two fields. Everything else is packaging.**

### The law

> **Nothing is done unless there is evidence.  
> Nothing is finished unless there is a next.  
> Nothing is remembered unless it was done.**

| Word | Meaning (non-negotiable) |
|------|---------------------------|
| **Done** | Has **evidence** (artifact / hash / exit / bill) — not chat |
| **Finished** | Has **next** — what the world must do now, or `chain complete` |
| **Remembered** | Only **done** things may enter evolution memory |

That is the whole product.  
Rungs 1–5, dominos, memory = **different costumes** for the same atom.

### The atom

```text
FACT
  claim     — what was said
  evidence  — empty ⇒ not done (CLAIMED / ILLUSION)
  next      — empty ⇒ illegal (Gilbert)
```

If you only ship **Fact**, you still have Coherence.  
If you ship seven rungs without Fact, you have a brochure.

---

## What 320 IQ refuses

| Refuse | Why |
|--------|-----|
| Soft “success” with no evidence | Mandela / illusion |
| Soft “done” with no next | Gilbert — nobody told what to do |
| Remembering vibes | Memory becomes mythology |
| Features that don’t emit a Fact | Complexity without law |
| Competing with AI review *opinions* | Opinions aren’t evidence |

---

## What 320 IQ maximizes

1. **One screen of truth** — claim / evidence / next  
2. **One habit** — before merge: every open fact either has evidence or blocks  
3. **One flywheel** — done facts with lessons compound; undones do not  
4. **Dominoes** — just Facts ordered so next points at the next Fact  

---

## Builder rule (tattoo this)

> When adding code, ask:  
> **Does this create or enforce a Fact?**  
> If no — delete it.  
> If yes — keep it stupidly clear.

180 IQ adds a module.  
320 IQ deletes a module and strengthens the law.
